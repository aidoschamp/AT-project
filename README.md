# Playing the game:
To properly play the game download [AT-project.zip in the latest release](https://github.com/aidoschamp/AT-project/releases/), unzip and launch the .exe

# Using the engine:
Download the engine and press import in the top left, and import the project files

[Link to download engine](https://godotengine.org/download/windows/)

# Just to browse scripts
Find .gd files in VSC or other IDE, which are godots file extension for their scripts, all .gd files will be with their respective scene (.tscn) files
